
# Pokémon Anime Cries - Gen1Recomp Mod

A [Gen1Recomp](https://github.com/bryanthaboi/gen1recomp) mod that replaces the original in-game Pokémon cries with audio taken from the English Pokémon anime series.

The initial release covers all **151 Pokémon from Generation 1**.

Support for Generation 2 Pokémon (Gold, Silver and Crystal) is planned for a future release.

[Pokémon Anime Cries Mod - Video Demonstration Youtube Link](https://www.youtube.com/watch?v=99U80CECDY4)

## Features

This mod replaces Pokémon cries in the following situations:

- During battles
- Depositing, withdrawing and releasing Pokémon through the PC
- Viewing Pokémon stats in the Pokémon menu
- Viewing a Pokémon's data page in the Pokédex
- Selecting the "Cry" option in the Pokédex
- Interacting with the Pokemon in the overworld
- And more...

The aim is to give each Pokémon a cry that closely resembles how it sounds in the original English Pokémon anime.

## Supported Games

The mod is intended to support the following Gen1Recomp games:

- Pokémon Red
- Pokémon Blue
- Pokémon Yellow
- Pokémon Gold
- Pokémon Silver
- Pokémon Crystal

**Note:** Generation 1 is the initial focus. Generation 2 support and compatibility will be developed and tested separately.

## Audio Sources

The vast majority of the Pokémon cries used in this mod were taken from the early English Pokémon anime seasons.

Any others were sourced from Japanese Episdodes (Nidoking was one of them)

The audio was sourced from official Pokémon anime episodes. No cries were sourced from impersonators or fan-made recreations on YouTube.

## How I Created the Cries

Creating the audio for all 151 Pokémon was a lengthy process. The following is an example of the workflow I used for Butterfree.

### 1. Find an Anime Appearance

First, I searched for a ["Who's That Pokémon?"](https://bulbapedia.bulbagarden.net/wiki/List_of_Who%27s_That_Pok%C3%A9mon%3F_segments) segment featuring Butterfree.

If a suitable segment wasn't available, I used [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Butterfree_(Pok%C3%A9mon)#Major_appearances) to identify episodes in which Butterfree appeared.

### 2. Extract the Audio

I extracted the audio from the relevant segment or episode and imported it into Logic Pro.

I then searched through the audio for Butterfree's vocalisations and other sounds.

### 3. Isolate the Cry

I cut out the relevant Butterfree sounds and used Logic Pro's Stem Splitter to isolate the vocal elements.

This helped remove as much background music and surrounding noise as possible.

### 4. Process the Audio

I normalised the audio and trimmed each clip to an appropriate length.

### 5. Test the Cry In-Game

I tested the resulting sound in Gen1Recomp and selected the version that felt most appropriate for the Pokémon.

I then repeated this process for the remaining Pokémon.

Yes, this took a very long time. I went through over 100 anime episodes, extracted audio, processed individual sounds and tested cries in-game for all 151 Pokémon.

## Installation

You can either:
- Click the "Releases" button on this GitHub page and download the zip file and import that as a "Import Mod .zip" file the Gen1Recomp application.
- Install this in the Gen1Recomp application by searching for the mod "Pokémon Anime Cries"
